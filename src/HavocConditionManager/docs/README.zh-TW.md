# 浩劫詞條管理器

配置 SoloPlay 任務詞條，並整體調整敵人排程。HCM 提供整體調節，可選的 Havoc Enemy Director 對同一套遊戲模板逐項精調。Realms 房間使用本地主機的設定。

詞條事件的機率隨機流在 HCM「整體調節 → 隨機種子」設定；HED「導演 → 隨機種子」分別設定自身編隊排程與原生駐軍佈局。關閉固定種子時沿用任務種子；HCM 無法取得任務種子時，每局只隨機生成一次後備用值。開啟後可輸入 1–2147483646 的整數，關閉會保留輸入值，修改用於下一局。這些種子不選擇任務地圖，也不統一原生屍潮、特感、怪物和指令碼事件的全部隨機性；Lua 作者直接使用 math.random 時仍屬於獨立的原生隨機來源。

## 原始碼與可選詞條集合

[HCM 公開原始碼倉庫](https://github.com/Darktide-mod/HavocConditionManager) · [HCM 下載](https://github.com/Darktide-mod/HavocConditionManager/releases)

[HavocConditionPacks 浩劫擴充詞條集](https://github.com/Darktide-mod/HavocConditionPacks) 是 HCM 的可選擴充，單獨提供「狂暴攻勢」及其所需的額外動畫資源。狂暴攻勢將敵人的常規近戰攻擊與動畫速度提高 20%，同步命中、連擊與掃擊時機。目前僅支援本地單人／機器人房間，兩處未匹配的首領連招保留原版行為。

HCM 自身提供詞條管理、整體強度調節、內建「禁止醫療」和外部 DIY 載入，使用這些功能不需要安裝集合包。禁止醫療直接從 HCM 目錄讀取；集合包的詞條也保存在自己的模組目錄，由 HCM 直接載入。讀取時不會解壓檔案，也不會替玩家勾選效果。

如需使用集合包，從 [HavocConditionPacks 下載頁](https://github.com/Darktide-mod/HavocConditionPacks/releases) 取得專用安裝 ZIP，把 HavocConditionPacks 放入 mods，載入順序排在 HavocConditionManager 後。關閉遊戲，按集合包說明安裝動畫資源；啟動後在 HCM 中勾選狂暴攻勢。僅修改 JSON／Lua 時，在大廳重新整理後用於下一局；修改動畫資源則需要重新啟動遊戲。

集合包獨立攜帶 CMD／PowerShell 安裝器和動畫補丁，HCM 安裝 ZIP 不包含這些檔案。已有 AppData 外部 DIY 繼續可用，同 ID 的舊副本保留在磁碟上，不重複載入。安裝和上傳 Nexus 時請使用各模組的專用安裝 ZIP；GitHub 的 Source code ZIP 包含整個倉庫及歷史發佈。拆分不代表已通過 Nexus 掃描。

## DIY 詞條

「禁止醫療」保留開局已通電的醫療站但將次數設為 0，移除需要附近電池的醫療站與配套電池，禁止生成醫療針劑與醫療包；其他治療仍可使用。

DIY 詞條與原生詞條共用主介面的「詞條配置」列表。分類順序為浩劫、金級、活動、DIY、全部、已啟用；已載入的 DIY 條目也會進入全部和已啟用篩選。懸停可閱讀適用物件、效果數值和觸發說明，長說明支援滾輪翻頁。HCM 應用所有已啟用且勾選的詞條，不設數量配額。

詞條可按敵人型別和標籤篩選玩家或敵人，修改敵人初始生命，疊加被動屬性與關鍵詞，響應原生戰鬥事件，排程臨時疊層，改變已支援的資源和狀態，併發出具名訊號。還可暫停已接入的原生刷怪節奏類別，或向 HED 請求有限增援。時間、機率、冷卻、逐單位／全域性作用域和觸發次數均有明確欄位。

增援動作需要可選的 Havoc Enemy Director。HED 的部署及原生模板規則可檢查已生效的 DIY 詞條 ID 和具名訊號。普通 DIY 增援會透過共用刷怪路徑保留來源標記；入隊後仍遵守原生落點、容量與節奏檢查。

docs/diy 提供三語手冊、模板、完整原生識別符號目錄，以及圖片 120 行設計的逐行評估。評估明確區分已支援、部分支援、需要新增適配及規則不明確的方案，模板並未實現全部圖片效果。Realms 客機接收房主核准的自身效果，同步失效後清除過期效果。

## 詞條與任務設定

- 匯入當前 SoloPlay 詞條列表，將可用條目分為浩劫、金標／漩渦、活動和通用。
- 新增或刪除詞條，沒有固定槽位上限。多個詞條包含同一原版機制時只載入一次。
- 在任務頁選擇地圖、陣營、難度和環境。不支援的地圖／環境組合回退為預設環境。
- 應用所選詞條的原版拾取物、醫療站和危險物設定。衝突效果仍遵循遊戲自身的覆蓋規則。

可選內容取決於已安裝的遊戲和 SoloPlay。HCM 不另行定義浩劫或金標詞條。

## 整體調節

從模組選項開啟 HCM，進入“整體調節”。主介面顯示強度滑條和聯動數值，20 項單獨控制元件收在“高階設定”中，詳細說明放在標題懸停提示中。

HED 也沒有額外覆蓋時，1 檔保留所選地圖、難度和詞條下的原版刷怪配置。2～10 檔讓普通敵人緩慢增加，精英、特感和怪物的投入增長更快。中間檔位按以下錨點插值；整數額度允許相鄰檔持平。檔位表示組合預設，不代表實測難度或擊殺數量的倍數。

- 沿途人數：1／5／10 檔分別為 1×／1.2×／1.5×。營地數量和事件預算為 1×／1.1×／1.25×。
- 屍潮與小股潮的單波普通人數：1×／1.1×／1.25×。屍潮頻率為 1×／1.08×／1.2×，小股潮頻率為 1×／1.05×／1.1×；普通屍潮波數保留原版。
- 屍潮編成與巡邏隊中已有的精英人數：1×／1.75×／3×，普通成員使用獨立人數設定。原有 8 名精英和 8 名普通兵的巡邏隊，在精英人數 3× 時請求 24 名精英和 8 名普通兵。沿途敵群和點數事件保留原版抽選比例，透過人數和預算增加投入。
- 特感容量：1×／2×／3×，補充頻率為 1×／2×／3.25×，爆發額度為 1×／3×／6×。容量與頻率疊加形成名義投放能力，仍受原版暫停、按玩家人數計算的限制和出生檢查影響。
- 地圖怪物遭遇額度：1×／4×／8×。精英巡邏遭遇額度：1×／3×／6×；巡邏次數與每隊人數分別計算。
- 協同戰術額度：1×／2×／3×。受支援攻勢的戰鬥負荷上限由 35 提高到 70、105；中等負荷下界保持 8，有效人數、戰鬥階段和其他原版條件繼續生效。HED 可以在調整後的條件上追加要求，或明確替換條件列表。
- 常規戰鬥容量：1×／1.5×／2×，恢復階段時長為 1×／0.85×／0.7×。10 檔存活敵人加待生成請求的總容量門檻為 290，難度 5 的屍潮門檻為 190。詞條遭遇數、持續加壓、任務目標及獨立指令碼事件限制保留各自設定。

巡邏與怪物先使用未佔用的地圖預設遭遇點，溢位額度等待後續有效遮擋位置。兩個後補佇列共用至少 20 秒的間隔，按各自初始溢位額度分配機會；另一類連續成功補入最多三次後，已就緒的佇列會獲得一次機會。一類受阻或生成失敗時，另一類可以嘗試，只有生成成功才扣額度。已有 3 只普通地圖怪物存活時暫緩額外 Boss，同時最多保留 2 支額外巡邏隊。原版暫停、可用位置和任務時長仍可能使額度未用完。

路線與後補精英巡邏隊逐個建立成員，相鄰成員至少間隔 0.15 秒，保留原版兵種、隊伍音效和單位初始化。路線巡邏保持原版編隊跟隨，行走目標取已經驗證的玩家所在層；後補巡邏使用當前交戰目標。前方點位必須對所有有效隊員不可見，距每名隊員（包括 BOT）至少 35 米，並在主路線上領先 30–120 米。前方點位不合適時，允許改用已經驗證的附近遮擋點：距每名隊員至少 20 米、距最近隊員不超過 60 米，也可以位於側面或後方。沒有合適點位則延後剩餘成員。出生安全區限制和有限遭遇額度繼續生效；巡邏隊全員建立完成後才扣除這一隊的額度。

額外巡邏、遭遇後補和回收補投均在生成前檢查通行。候選點必須存在從敵人位置到當前玩家實際所在導航層的完整路線。地形和門連線由原生尋路決定，HCM 不再額外檢查門狀態或開門許可權。通常的額外遭遇優先使用前方約 60 米處的遮擋點；回收補投需要重新選點時優先嚐試附近候選，已有可用的共用點位仍會複用。附近點必須對所有有效隊員不可見、距每人至少 20 米、距最近隊員不超過 60 米。檢查未完成或不透過時不會先生成敵人試路。編隊展開後的每個位置還必須能走回已驗證的集結點；實際生成前重新確認路線有效性、玩家位置、距離和視野。延遲補投請求在原版佇列真正建立單位時再次檢查。

選點共用一項非同步尋路和一條可檢查有效性的路線，每秒最多啟動一次新查詢。候選表最多保留兩個原生前方點、兩個原生附近點和四個區域性導航點；原生附近點優先考慮玩家所在樓層。區域性取樣在玩家實際所在導航層周圍檢查最多八個偏移位置，交替使用 28 米和 40 米半徑，全域性至少間隔四秒；投影到導航面仍須透過完整通路檢查。成功結果供成員複用，補投每次只展開最多八個位置，減少過大的編隊範圍。遊戲執行緒不等待尋路，回收判定本身仍不做尋路。

普通屍潮和任務事件由原版邏輯選擇點位、出生門，並執行調整後的模板節奏。法庭密牢旋轉樓梯事件也保留地圖原有的後方入口。HCM 不為這些出生增加導航路徑審批或等待。

選檔會替換全部 20 項 HCM 數值，單項修改後顯示“自定義”。完全匹配舊曲線預設的儲存值會遷移到新曲線的同一檔位，其他自定義值和 HED 覆蓋保留。修改自動儲存並在下一局生效。

到期出生器分幀執行，保留各自佇列、生成順序和完成通知。普通與協同屍潮在中央佇列積壓時暫緩下一波，待發波次和受臨時容量限制的地圖敵人計劃繼續保留。重複增益容量警告按次數彙總，Buff 事件池維持 300。

已知排程巡邏的跟隨者失去隊長後，可透過原版警覺／仇恨方法恢復接敵一次，相鄰恢復至少間隔 0.15 秒。檢查複用已有感知更新，保留任務歸屬、玩家所有權和穿越動作保護；正在逐個回收的隊伍不會被自身回收過程重新喚醒。

## 自動回收後方敵人

本地主機任務中，所有強度檔（包括 1 檔）均啟用回收。已觀察到參戰的普通兵或精英，以及已投放的排程巡邏，距每名存活隊員（包括 BOT）至少 35 米、連續 30 秒沒有重新接敵後可以回收。每 5 秒取樣一次，排隊會延長實際等待。真實傷害重置同一段計時；移除前再次檢查當前距離和原版即時視線。

對於已參戰或已投放的巡邏，移動、繞圈、路線資料缺失、巡邏標記和整個指令碼事件的狀態不會使其免於回收。巡邏成員逐個判斷，不等待全隊。原版普通兵和精英在建立時被識別，包括非必要目標的事件波次，不依賴出生來源白名單。必要任務目標、外部控制或玩家所有單位、無敵敵人、特感、Boss、隊長和同伴繼續受保護。標記或常駐效果本身不構成永久豁免；實際持續傷害會重置計時。

從未參戰的原生地圖散怪也可回收：線上性關卡中，原生出生位置已落後於原版快取的隊尾路線進度至少 60 米，且敵人仍在該位置 12 米範圍內，才進入同一套 35 米距離、不可見和 30 秒計時檢查。只讀取現有進度，不為敵人投影路線或尋路。尚在前方、夾在隊員之間、離開原記錄位置太遠、開放地圖或記錄不明的散怪繼續由原版處理。隊員折返會取消回收；已回收記錄在引擎完成刪除前不會重新啟用。

複用原版感知排程，只保留最多 64 個已就緒單位引用的固定環形佇列。回收判定不儲存運動歷史，不做主路線投影，不查剩餘路徑，不啟動獨立尋路，也不掃描全圖。最終嘗試至少間隔 0.25 秒，每秒最多四次、每次更新最多一隻，並檢查存活隊員的即時視線。慢幀後不會集中補執行。已知巡邏的孤立跟隨者仍可透過原版警覺／仇恨方法恢復接敵一次。

回收使用原版移除和重新生成；每個原單位最多補投一次相同兵種。相容額度合併成最多 64 人的小批次，同時最多 32 條記錄、256 個待補單位。已接受的額度保留到本局結束，不再因遭遇受阻而過期；超過固定容量的額度丟棄。可生成的批次輪流補入，暫停的類別不會擋住後面的可用類別。補投請求至少間隔 0.25 秒，每秒最多四隻、每次更新最多一隻，全域性最多一個 HCM 補投請求等待原版佇列處理；批次之間不再額外等待八秒。原版排程、容量、安全區、距離、視野和生成前通路檢查繼續生效。失敗請求保留額度，補投單位不再產生第二次補投。生命值重新初始化，隨機詞條可能重抽；已知的原生命倍率保留。腐爛護甲的非死亡清理處理繼續生效。

## 精調與設定儲存

安裝 Havoc Enemy Director 後增加“詳細調節”頁。先應用 HCM 整體倍率，再由 HED 對單個欄位寫入精確值；原版難度和詞條修正仍可能繼續改變最終結果。任務戰鬥節點預算有一項例外：節點基礎值與原版修正計算後，HCM 事件預算倍率繼續調整最終預算及原版預算封頂。

修改自動儲存，在下一局開始時生效；正在執行的任務保持開局配置。DMF 開關在大廳立即生效，任務中切換則延後應用。關閉 HCM 會恢復 SoloPlay 選單，並在後續任務中暫停 HED。

首次使用會從舊 HCM 選擇中匯入仍有效的原版詞條 ID，省略已移除的別名，保留原始儲存值。舊版按敵種分類的倍率和自定義生成器設定不轉換為原版模板修改，請從新預設值重新配置。

英文、簡體中文和繁體中文隨遊戲語言切換；為區分具體模板，必要處保留原版識別符號。

包 ID、版本、依賴、衝突與能力均經過校驗。已選擇條目的本地 Lua 在權威端執行，具備獨立模組環境、資源快照和清理回撥；包更新用於下一局。死靈聯機一致性覆蓋 JSON、Lua、資源及依賴指紋，網路不傳遞可執行 Lua。附帶中英繁三語包規範、介面說明與完整示例。

「DIY 管理」直接讀取模組目錄中的「禁止醫療」，無需解壓範本，也不會寫出內建詞條副本。內建套件保持載入，效果仍由主介面勾選決定。外部目錄維持 %APPDATA%/Fatshark/Darktide/HavocConditionManager/diy/packages，修改後重新整理；當前任務保持開局快照。同 ID 的舊外部副本保留在磁碟上，優先使用內建或集合包版本。

## 使用前提

需要 Darktide Mod Loader、Darktide Mod Framework 和 SoloPlay。Realms 為可選聯機依賴，Havoc Enemy Director 為可選精調擴充套件。其他替換同一原版模板或排程方法的模組可能衝突。

## Vortex 安裝

- 關閉遊戲並安裝前置。使用 Install From File 匯入本 ZIP，啟用後選擇 Deploy Mods。
- 在 Load Order 中將 HavocConditionManager 放在 SoloPlay 後；如安裝 HavocEnemyDirector，將其放在 HavocConditionManager 後。
- 重新啟動遊戲，從模組選項開啟浩劫詞條管理器。

## 手動安裝

- 關閉遊戲。升級時先移除舊 HavocConditionManager 安裝資料夾，再解壓新包；已儲存設定存放在其他位置。
- 將 ZIP 解壓到 Darktide/mods，得到 mods/HavocConditionManager。
- 在 mods/mod_load_order.txt 中單獨一行填寫 HavocConditionManager，排在 SoloPlay 後；可選的 HavocEnemyDirector 排在其後。
- 重新啟動遊戲，從模組選項開啟 HCM。
