# 詞條匯入行為

HCM 讀取 SoloPlay 的浩劫和普通詞條排序列表。只有當前遊戲存在對應詞條及其全部機制時，條目才可選；非預設主題環境和難度修正保留在任務頁專用選擇器中。關閉 HCM 時恢復原目錄。

SoloPlay 浩劫條目保留浩劫分類；原版 flash_mission 條目歸入金標／漩渦，活動 ID 或活動描述歸入活動，其餘為通用。HCM 不註冊詞條別名，不復制其他模組的詞條定義，也不修改網路查詢表。

同一原版機制按識別符號只載入一次。所選順序和原版覆蓋規則仍有意義：額外拾取物數量相加，醫療站與任務設定遵循原版覆蓋，危險物設定使用最後一個相關所選詞條。任務結束清理自身詞條監聽器。

舊選擇中的有效 ID 遷移到 SoloPlay 的 HCM 選擇鍵，無效別名被跳過，原始舊值保留。預設倍率保持原版模板；HED 為可選擴充套件。
