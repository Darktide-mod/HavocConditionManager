# 词条导入行为

HCM 读取 SoloPlay 的浩劫和普通词条排序列表。只有当前游戏存在对应词条及其全部机制时，条目才可选；非默认主题环境和难度修正保留在任务页专用选择器中。关闭 HCM 时恢复原目录。

SoloPlay 浩劫条目保留浩劫分类；原版 flash_mission 条目归入金标／漩涡，活动 ID 或活动描述归入活动，其余为通用。HCM 不注册词条别名，不复制其他模组的词条定义，也不修改网络查找表。

同一原版机制按标识符只加载一次。所选顺序和原版覆盖规则仍有意义：额外拾取物数量相加，医疗站与任务设置遵循原版覆盖，危险物设置使用最后一个相关所选词条。任务结束清理自身词条监听器。

旧选择中的有效 ID 迁移到 SoloPlay 的 HCM 选择键，无效别名被跳过，原始旧值保留。默认倍率保持原版模板；HED 为可选扩展。
