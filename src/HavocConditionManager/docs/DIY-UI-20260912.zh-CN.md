# DIY 主界面、模板与狂暴攻势（4.4.5-test.1）

DIY 词条现在与原版词条共用「词条配置」页面。分类顺序为：浩劫、金级、活动、DIY、全部、已启用。DIY 同时计入「全部」和「已启用」，悬停可以阅读详细效果；过长说明可滚动翻页。主界面保留自定义效果总开关，勾选词条会自动开启它。选择自动保存，下一局生效。

「DIY 管理」负责解压模板、刷新加载、复制目录路径、导出包、粘贴 JSON、启用或停用包，以及查看完整说明。点击包名只查看说明；要把词条用于下一局，请到「词条配置」中勾选。

## 使用模板

1. 重启游戏，打开 HCM 的「DIY 管理」。
2. 点击 **解压模板DIY词条**。
3. 「狂暴攻势」与「禁止医疗」两个模板会写入 DIY 包目录并立即加载；其中包含「狂暴攻势」和已经修改的医疗物资词条。回到「词条配置」即可查看与选择。

模板内置在模组中，未解压时不会成为额外的可选词条。已有外部包仍正常加载。解压会覆盖同名包，旧包会移入相邻的 `package-backups` 目录，随后加载新内容。解压本身不会把所有词条勾选启用。模板使用稳定的词条标识，因此覆盖后已有勾选可以保留。

模板的中文说明已重写，涵盖作用对象、触发方式、持续时间、数值和限制。界面会补充实际配置的规则说明，并清理格式控制符、图标字符与代码式字段展示。保留的「禁止治疗」名称对应此前确定的医疗物资规则：已插电池的医疗站保留但次数归零；空电池舱的医疗站及配套散落电池移除；不生成医疗兴奋剂和医疗包。此词条不再全局禁止治疗。

## 狂暴攻势

作用于全部敌人，包括杂兵、精英、特感和 Boss：

- 移速统一提高 30%，走路与跑步动画同步处理；变种人直接计算速度的冲锋路径也包含在内。
- 近战与远程攻速提高 40%，前摇、命中、投掷、收招和攻击动画使用相同的速度比例。
- 受击硬直与撞墙眩晕保持原版。
- 继续保留攻击冷却缩短 80% 和解除围攻配额等待，仍需满足射程、视线和目标锁定等条件。

本版为本地主机动画同步测试版。离线检查通过不代表已经完成游戏内视觉验收；动画显示、根运动与音效事件仍需进局确认。远程客户端未增加动画时钟同步协议。参见 [本次变更与验证范围](Frenzied-assault-4.4.5-test.1.zh-CN.md)。

用户提到的蓝色污染兴奋剂，在核对的原版 1.12.5 代码中属于防御强化：覆写为甲壳护甲判定、命中质量翻倍。红色污染兴奋剂才提供近战攻速加成并放宽出手限制。「狂暴攻势」参考了后者的出手机制，并按本次要求额外处理移动速度和攻击前后摇。

核对位置：原版源码提交 `0f0cb4599` 的 `scripts/settings/havoc/havoc_mutator_local_settings.lua`、`scripts/settings/buff/havoc_buff_templates.lua`，以及敌人 AI、导航、运动和攻击动作实现。
