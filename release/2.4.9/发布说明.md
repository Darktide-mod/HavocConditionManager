安装 ZIP 的最外层只有 HavocConditionManager/，不含其他模组或嵌套压缩包。

Vortex：管理 Darktide → Install From File 导入此 ZIP → 启用 → Deploy Mods → 调整 Load Order。

手动：将 ZIP 解压到 Darktide/mods，得到 mods/HavocConditionManager；在 mod_load_order.txt 中添加此模组名称。

必需依赖：Darktide Mod Loader、Darktide Mod Framework、Solo Play

可选依赖：Realms — for player-hosted sessions、Havoc Enemy Director

具体加载顺序见三语正文。PNG 单独上传 Images，文案复制到页面；只将 files 中的 ZIP 上传 Files。
