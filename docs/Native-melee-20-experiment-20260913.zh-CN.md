# 狂暴攻势：原生近战 +20% 开发原型

2026-09-13。用户最终指定的幅度是 **+20%**，取代此前的 +40%。

**这是未安装、未通过实机验证的实验包，不是新的正式版本。** 正式包 HCM 4.4.7 和游戏安装目录保持原样。首次使用这种方案需要安装配套动画资源并重启游戏；仅刷新 Lua 包无法让已经加载的动画控制器增加新变量。

## 实现和开销

近战播放速度为原值 ×1.2，命中、扫击窗口、连击、动作结束时间、盾牌开闭与相关动作特效时间按同一比例缩短。时长变成原值的约 83.33%，而不是直接减去 20%。攻击距离、伤害和网络延迟补偿没有被当作时间缩放。

修改的是原生动画控制器的播放速度表达式。原表达式为常数的近战状态改为读取一个默认值完全相同的变量；单位首次近战时才设置变量，随后由引擎原有的动画求值推进播放与根运动。当前控制器已有的速度差异得到保留，例如原来就是快速连击的状态继续在其原速度上增加 20%。没有每秒扫内存、遍历动画层、重设动画播放进度、原生 DLL 或逐帧修补引擎时钟。

Lua 为每份动作数据准备一次时间表副本。近战每帧入口仍多一次轻量函数转发和缓存字段读取，用来让后续连击特效沿用同一份数据；不能称作绝对零开销。首次近战还会做最多 14 次变量名查询、设置该控制器实际存在的变量。待机、寻路、出门、翻越、射击等更新不参与这套逻辑。更高的实际攻击次数本身仍会增加游戏原有的碰撞与伤害工作量，实机帧率尚未测量。

这份原型不添加上一版的红针 buff、抗踉跄、攻击许可或粒子效果，也不增加移速或远程射速。常规近战走 `BtMeleeAttackAction`；扑人、投弹、抓取、传送推击等独立特殊行为没有纳入本次实现。

## 验证范围与使用限制

首次集成仅支持本地单人/机器人房间。联机客户机的资源一致性、后加入同步尚未完成，因此不能将本包当作多人正式版。加载器接受新增变量、运行中的动画混合、扫击碰撞、脚步与根运动均仍需游戏内验证。尚不支持通过普通包刷新即时替换动画资源；Lua 时序与资源必须配套。

本次没有更改正式版内置模板、死灵 UI、禁止医疗、游戏 mods、AppData 或 Vortex。实验 Lua 包使用相同的狂暴攻势标识，因此测试安装会替换用户目录里该词条的 Lua 包，安装器会先备份。

## 试验安装器

压缩包内的 `install_experiment.py` 默认仅检查，只有显式传入 `--install` 才写入。需 Python 3.11 及以上。先关闭 Darktide，使用自己游戏目录和 HCM 包目录运行：

```text
python install_experiment.py --game "游戏目录" --package-root "%APPDATA%/Fatshark/Darktide/HavocConditionManager/diy/packages"
```

这里的 `%APPDATA%` 是目录占位说明；传给 Python 前需展开成实际绝对路径。检查通过后，在同一命令末尾加 `--install` 才执行试验安装。安装器核验游戏执行文件、原始容器、数据库和所有载荷的 SHA-256，拒绝文件版本不符、补丁编号占用或旧包中出现不明文件的情况。写入范围仅限 54 个 `.patch_996` 文件、资源数据库、该狂暴攻势包的六个文件；不修改游戏 exe 或其他词条。

备份保存在安装器旁的 `backups` 目录。安装结果会给出 `installation.json` 的绝对路径。需要撤销时：

```text
python install_experiment.py --uninstall "备份 installation.json 的绝对路径"
```

卸载仅恢复/删除自己记录的文件，不递归清理目录；如果安装后文件被用户、游戏更新或其他工具修改，会拒绝覆盖。保留备份，不要手动将压缩包内的数据库文件覆盖到其他游戏版本。

首次实机应先确认游戏正常启动，再在本地机器人房间验证普通近战、狂战士连击、欧格林扫击、词条停用后的恢复，以及出门、翻越、射击等动作。完成这些检查与真实帧率对比前，不应提升为正式包。

## 来源与可复核文件

游戏 Lua 来源为本机固定提交 `0f0cb45991e9305ef4a7b925370792d7d6035f95`，对应 1.12.5。它是已发布游戏 Lua 的社区归档，不能称为官方内部 Git 仓库。动画二进制来自用户本机同一版本安装资源。

原生控制器变量可以参与播放与混合表达式，见 [Autodesk 动画控制器文档](https://help.autodesk.com/cloudhelp/ENU/Stingray-Help/stingray_help/animation/animation_controllers.html)。本机引擎没有通用文档中的 `animation_has_variable` 名称，因此实现使用实际存在的 `animation_find_variable`，并处理未找到的情况。格式核对参考 Bitsquid Blender Tools 的固定提交 `d8061ad4c7440f43b6a6628477f704de5c43f3ec`；GPL-3.0 参考文件保留在分析目录，未作为产品运行代码打包。

工作区复核脚本位于 `build/checks/native-melee-controller/`；原型位于 `experiments/native-melee-20/`。正式 4.4.7 压缩包 SHA-256 仍为 `d7d96bbcf3a9bb849b4c0bd6bcf433c009fc98cd2695dbf9b6aadee46ef7425d`。
