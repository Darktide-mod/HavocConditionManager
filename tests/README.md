# Project checks

Run Test.ps1 or tests/run.py. The 25 active groups cover native templates, intensity/composition, capacity/pressure, spawn queues, encounter ownership, common/elite recovery, required event targets, buff cleanup, UI, optional integration and release structure.

native_recycling_harness.py provides the native perception, minion spawn/despawn, roamer, patrol and group lifecycle fixtures. native_straggler_tests.py checks the simple 35-metre/30-second rule, one timer after real damage, individual patrol retirement, 240-unit completion, zero recovery route queries and bounded replacement allowance. Native queue consumption rechecks current visibility, player position, safe zones, retained allowance and session ownership.

native_recycling_recovery_tests.py executes the real ascender event node, authored doors and queue-ID accounting. Non-objective leftovers retire while an event is active; explicitly required targets remain. Full and expanded queues preserve 256/300 native requests and original positions.

native_recovery_safety_tests.py checks blocked recovery with no diagnostic output, including a 240-unit, 900-second fixture with zero added path/physics queries or boxed-vector allocations. It retains last-moment cancellation, generic native creation tracking and six-member replacement checks. Queue conservation is inspected only in the test harness; production has no reporting counters.

native_retirement_regression_tests.py retains actual distant-target selection, modifier handling, Buff.destroy and the rotten-armour stop/death payload. Native removal/recreation and ordinary deaths remain distinct.

The game Lua is read from dev-support/game-source; sparse missing files can be read from its captured Git revision. Physics, real map navmesh, rendering, networking and entity creation remain explicit engine boundaries. These tests establish Lua behavior and call limits, not measured in-game FPS or proof that every real-map leftover has been eliminated. Earlier movement/progress tests are superseded by the simple recovery contract.

native_reachable_placement_tests.py checks pre-spawn directional reachability, incomplete-route refusal, a complete 21-crusher nearby deployment, delayed results, actual player floor, per-position connections, dynamic invalidation at native queue consumption and cleanup before native Roamer.destroy. placement_engine_fixture.py explicitly models engine AStar, live-path and projection results; it does not simulate the map navigation mesh. Resource assertions cover one shared search object, at most one new search per second and bounded polling. Native mission/horde position selection remains outside the extra-spawn guard.

native_rear_ambient_tests.py executes the native cached rear-progress getter, passive retirement/dead-record cleanup and queue lifetime. It covers ahead and between-team enemies, absent or uncertain records, moved roamers, open maps, all existing ownership and visibility guards, returning teammates and remembered engagement. A 240-enemy fixture drains by 95 seconds including its initial 30-second wait, with at least 0.25 seconds between removals, one removal per update, a bounded 64-slot ring, no slow-frame catch-up and zero recovery route queries.

native_refill_optimization_tests.py verifies actual native reconstruction of 103 retained credits after the former expiry, fair admission past a paused head class, non-head completion/cancellation, one globally in-flight request and native group unlocking. It exercises native capacity pressure and local same-floor candidates when authored points are absent, with explicit AStar/mesh/physics boundaries and bounded local projection/search work. Existing straggler tests now verify 256 retained credits plus 44 capacity discards from 300 retirements, and delayed native queue consumption without expiry.

native_door_placement_tests.py executes native door state/opening and graph component methods to set up real Lua states, then forbids any HCM door, graph or layer query. Successful native paths admit closed, disabled or unresolved door links without interacting with them. It checks all terrain categories, 21 native crusher creations, delayed results and final queue consumption. Invalid native paths still cancel creation and retain allowance. AStar and animation/navigation engine results remain explicit fixtures, not a replay of a specific mission door.
